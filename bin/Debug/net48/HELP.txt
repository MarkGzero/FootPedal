FOOT PEDAL APP - COMMAND SYNTAX GUIDE
=====================================

OVERVIEW
--------
This application allows you to control your computer using a USB foot pedal.
Compatible with: OLYMPUS IMAGING CORP. HID FootSwitch RS Series (VID_07B4&PID_025F)

The app runs in your system tray (near the clock) and monitors for foot pedal button presses.
Each of the 4 pedal buttons can be configured to perform different actions.


DEVICE STATUS INDICATOR
-----------------------
The system tray icon shows the foot pedal connection status:

  Sky Blue Icon  = Foot pedal is connected and ready
  Red Icon       = Foot pedal is disconnected

You will receive a notification when the device is unplugged.


SYSTEM TRAY MENU
----------------
Right-click the tray icon to access:
  • Settings        - Configure pedal button commands
  • Validate Config - Check config.json for errors and structure issues
  • View Log        - Open debug.log file to see activity and troubleshoot issues
  • Exit            - Close the application

Double-click the tray icon to open Settings directly.


CONFIGURATION FILE LOCATION
----------------------------
Config and log files are stored in:
  %APPDATA%\FootPedalApp\

Files:
  • config.json  - Pedal commands and browser paths
  • debug.log    - Application activity log


You can configure each pedal with different types of commands:

1. KEYBOARD HOTKEYS
-------------------
Send keyboard shortcuts to Windows applications.

Format: MODIFIER+KEY

Modifiers:
  WIN   - Windows key
  CTRL  - Control key
  ALT   - Alt key
  SHIFT - Shift key

Examples:
  WIN+1           - Open taskbar app at position 1
  WIN+2           - Open taskbar app at position 2
  CTRL+C          - Copy
  CTRL+V          - Paste
  CTRL+Z          - Undo
  ALT+F4          - Close window
  CTRL+SHIFT+ESC  - Task Manager
  WIN+D           - Show desktop
  WIN+L           - Lock computer

HOW TO CAPTURE HOTKEYS:
  1. Click the "Capture" button next to the pedal textbox
  2. Press the key combination you want (e.g., press Win+1)
  3. The hotkey will be automatically captured and saved
  4. The textbox returns to normal editing mode

ALTERNATIVE: If capture button doesn't work for certain key combinations:
  → Click "Config" button to open config.json
  → Edit the Pedals section directly (e.g., "Left": "CTRL+SHIFT+F1")
  → Save the JSON file
  → Click "Save" in Settings window to reload


2. RUN PROGRAMS
---------------
Launch applications or executables with optional arguments.
Type these commands manually in the textbox.

Format: RUN:program.exe [arguments]
Format: RUN:"path with spaces.exe" [arguments]

Examples:
  RUN:notepad.exe
  RUN:notepad.exe C:\file.txt
  RUN:calc.exe
  RUN:explorer.exe C:\Users
  RUN:cmd.exe /k dir
  RUN:"C:\Program Files\MyApp\app.exe"
  RUN:"C:\Program Files\MyApp\app.exe" --arg1 value1
  RUN:C:\Users\mark\AppData\Local\Discord\Update.exe --processStart Discord.exe

Note: Use quotes around paths that contain spaces!


3. OPEN URLs
------------
Open websites in your default browser or a specific browser.
Type these commands manually in the textbox.

Format: URL:address
Format: URL:browser address

Supported browsers: chrome, firefox, edge, brave

Examples:
  URL:https://google.com
  URL:https://youtube.com
  URL:chrome https://gmail.com
  URL:firefox https://github.com
  URL:edge https://bing.com

Browser Path Configuration:
  - Click "Config" button to edit browser paths in config.json
  - Default browser paths are set for typical installations
  - Customize if browsers are installed in non-standard locations


4. EMPTY/DISABLED PEDAL
-----------------------
To disable a pedal button, simply leave the textbox empty.
The pedal will not perform any action when pressed.


HOW TO USE THE SETTINGS WINDOW
-------------------------------
The settings window uses a dark theme (#1E1E1E background) for comfort.

1. For Hotkeys:
   - Click "Capture" button next to the pedal you want to configure
   - Press your desired key combination
   - The hotkey is captured automatically
   - Button returns to normal mode

2. For RUN and URL commands:
   - Type directly into the textbox (e.g., RUN:notepad.exe)
   - No need to click Capture button for typed commands

3. Double-click textbox for longer commands:
   - Double-click any textbox to open a larger, resizable editor window
   - Text will wrap for better visibility of long commands
   - Useful for long file paths or complex RUN commands with many arguments
   - Press OK to save, or Cancel to discard

4. Edit config.json directly:
   - Click "Config" button at top-right to open config.json in Notepad
   - Useful for editing browser paths or bulk changes
   - File location: %APPDATA%\FootPedalApp\config.json
   - Changes take effect immediately when you click Save in Settings
   - No need to restart app after config.json edits (just click Save in Settings)

5. Enable/Disable Top Pedal:
   - Check "Enable Top Pedal" if you want to use the 4th button
   - Leave unchecked if you only use 3 pedals
   - Disabling hides the Top pedal configuration in the UI

6. Help Button:
   - Click "?" button at top-right to view this help file
   - Help file opens in Notepad for easy reference

7. Save your changes:
   - Click "Save" to apply all changes immediately
   - Click "Cancel" to discard all changes and close window
   - Settings are saved to config.json in %APPDATA%\FootPedalApp\


TIPS
----
- Textboxes are freely editable - type RUN: and URL: commands directly
- Use "Capture" button only for keyboard shortcuts
- Hotkeys are shown in UPPERCASE (e.g., WIN+1, CTRL+C)
- For long commands: Double-click textbox for larger editor
- For RUN commands: Use full path if program is not in PATH
- For paths with spaces: Use quotes like RUN:"C:\Program Files\app.exe"
- URL commands: Include http:// or https:// in the address
- Check the log file for errors (View Log from tray icon menu)
- App runs on startup automatically (can be disabled in Task Manager > Startup)
- All settings are stored in %APPDATA%\FootPedalApp\config.json
- Default pedal configuration: Left=WIN+1, Middle=WIN+2, Right=WIN+3, Top=empty


ADVANCED: Config.json Structure
--------------------------------
The config.json file has two sections:

{
  "Pedals": {
    "Left": "WIN+1",
    "Middle": "WIN+2",
    "Right": "WIN+3",
    "Top": ""
  },
  "Browsers": {
    "Chrome": "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe",
    "Firefox": "C:\\Program Files\\Mozilla Firefox\\firefox.exe",
    "Edge": "C:\\Program Files (x86)\\Microsoft\\Edge\\Application\\msedge.exe",
    "Brave": "C:\\Program Files\\BraveSoftware\\Brave-Browser\\Application\\brave.exe"
  }
}

Note: Use double backslashes (\\) in JSON for Windows paths.


TROUBLESHOOTING
---------------
- Capture button not working for certain keys?
  → Some key combinations might not register in the GUI
  → Instead: Click "Config" button → Edit config.json directly
  → Type the hotkey manually (e.g., "CTRL+SHIFT+F1")
  → Save JSON file and click "Save" in Settings to reload

- Windows key combinations not working?
  → Make sure to capture them with the Capture button
  → Press the combination quickly (don't hold too long)
  → Try releasing and pressing again
  → If still failing, edit config.json directly
  
- RUN command fails?
  → Use full path to the executable
  → Wrap paths with spaces in quotes: RUN:"C:\Program Files\app.exe"
  → Check if file exists at the specified path
  → View Log to see exact error message
  
- URL not opening?
  → Include http:// or https:// in the address
  → Check browser name spelling (chrome, firefox, edge, brave)
  → If browser not found, system default browser will be used
  → Check browser paths in config.json (click Config button)
  
- Top pedal not working?
  → Enable it with the "Enable Top Pedal" checkbox in Settings
  → Make sure it's not just set to empty command
  
- Pedal buttons doing nothing?
  → Check if command textbox is empty
  → View Log to see if pedal presses are detected
  → Try pressing different pedals to isolate the issue

- Icon shows red but pedal is plugged in?
  → Try unplugging and replugging the USB cable
  → Press a pedal button to reactivate detection
  → Check Device Manager for "OLYMPUS IMAGING CORP. HID FootSwitch RS"
  → Make sure no other software is using the device exclusively
  
- No notification when unplugging?
  → Notifications only appear on disconnect (not reconnect by design)
  → Check Windows notification settings for the app
  → Notifications show for 3 seconds when device disconnects
  
- App not starting?
  → Check if already running in system tray
  → Delete config.json and restart (will reset to defaults)
  → View debug.log for error messages
  
- Settings not saving?
  → Make sure to click "Save" button before closing
  → Check if %APPDATA%\FootPedalApp folder is writable
  → View Log for save errors
  → Use "Validate Config" from tray menu to check for JSON errors

- Config file corrupted or has errors?
  → Right-click tray icon → "Validate Config" to check for issues
  → If validation fails, click "Config" button and fix JSON syntax errors
  → Common errors: Missing commas, missing quotes, incorrect backslashes
  → Remember: Use double backslashes (\\) in JSON paths
  → Delete config.json to reset to defaults
  
- Need to see what's happening?
  → Right-click tray icon → "View Log" to see debug information
  → Look for "Foot pedal connected" or "Foot pedal disconnected" messages
  → Device path should show VID_07B4&PID_025F for proper detection
  → Each pedal press is logged with button name and command executed
  → Log file location: %APPDATA%\FootPedalApp\debug.log


TECHNICAL DETAILS
-----------------
Device: OLYMPUS IMAGING CORP. HID FootSwitch RS Series
VID/PID: VID_07B4&PID_025F
HID Usage: Consumer Control (0x0C/0x01)
Buttons: Left, Middle, Right, Top (4 buttons total)
Connection: USB HID interface
Monitoring: Windows WM_DEVICECHANGE events for plug/unplug detection
